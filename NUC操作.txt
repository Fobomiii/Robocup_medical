说明：
- dry_run=true：不向 STM32 发送底盘速度，适合部署和只读检查。
- dry_run=false：允许真实运动；STM32 若已派发任务，服务启动后可能立即运动。

三、当前导航任务状态

timeout 5 ros2 topic echo --once \
  /navigate_to_pose/_action/status || true

常见状态：
- status: 2：任务正在执行。
- 如果 status: 2 且 dry_run=true，机器人不会移动，随后出现 Failed to make progress、spin failed、backup failed 是预期结果，不代表地图或 TF 损坏。
- 暂时不测试运动时，停止导航服务，避免不断恢复和刷日志：

sudo systemctl stop obstacle-detector.service


四、安全模式与真实运动模式

1. 切换到安全模式（不输出底盘速度）

sudo systemctl stop obstacle-detector.service
mkdir -p ~/.config
printf '%s\n' \
  'MEDICAL_NAV_DRY_RUN=true' \
  'ROS_DOMAIN_ID=77' \
  'ROS_LOCALHOST_ONLY=1' \
  > ~/.config/medical-navigation.env
sudo systemctl start obstacle-detector.service
sleep 8
ros2 param get /stm32_bridge dry_run

必须显示：Boolean value is: True

2. 切换到真实运动模式

警告：确认场地安全、底盘架空或急停可用，并确认 STM32 当前任务。服务重启后可能立即执行已存在任务。

sudo systemctl stop obstacle-detector.service
sed -i \
  's/^MEDICAL_NAV_DRY_RUN=.*/MEDICAL_NAV_DRY_RUN=false/' \
  ~/.config/medical-navigation.env
sudo systemctl start obstacle-detector.service
sleep 8
ros2 param get /stm32_bridge dry_run
timeout 5 ros2 topic echo --once /medical_nav/bridge_status

必须显示：Boolean value is: False
机器人开始执行时，bridge_status 中的 cmd_count 应持续增加。

七、调整膨胀区（临时参数）

# 查看当前值
ros2 param get /local_costmap/local_costmap inflation_layer.inflation_radius
ros2 param get /global_costmap/global_costmap inflation_layer.inflation_radius

# 设置局部、全局膨胀半径
ros2 param set /local_costmap/local_costmap inflation_layer.inflation_radius 0.30
ros2 param set /global_costmap/global_costmap inflation_layer.inflation_radius 0.30

# 确保膨胀层开启
ros2 param set /local_costmap/local_costmap inflation_layer.enabled true
ros2 param set /global_costmap/global_costmap inflation_layer.enabled true

# 数值越大，代价下降越快；数值越小，高代价区域越宽
ros2 param set /local_costmap/local_costmap inflation_layer.cost_scaling_factor 25.0
ros2 param set /global_costmap/global_costmap inflation_layer.cost_scaling_factor 25.0

# 清空并重建代价图
ros2 service call /local_costmap/clear_entirely_local_costmap \
  nav2_msgs/srv/ClearEntireCostmap '{}'
ros2 service call /global_costmap/clear_entirely_global_costmap \
  nav2_msgs/srv/ClearEntireCostmap '{}'

ros2 param set 修改的参数只在本次进程中有效；服务重启后恢复 YAML 配置。
